<DocSection id="intent" index="01" title="Why it exists" description="Structured facts should scan without looking like dashboard cards.">

Dossier Matrix groups related labels and values into one semantic record. The open grid preserves the editorial character of the portfolio while making roles, scope, runtime, and evidence status easy to compare.

**It should not become** a metric dashboard or a collection of decorative statistic tiles.

</DocSection>

<DocSection id="usage" index="02" title="Usage">

```astro
<DossierMatrix
  columns={2}
  items={[
    { label: 'Role', value: 'Product Engineer' },
    { label: 'Runtime', value: 'Astro / Native JS' },
  ]}
/>
```

</DocSection>

<DocSection id="variants" index="03" title="Variants">

- **Two columns** suits focused project or profile metadata.
- **Three columns** supports denser system records on wide canvases.
- Both contracts collapse to one reading column on small screens.

</DocSection>

<DocSection id="accessibility" index="05" title="Accessibility">

The component renders a native definition list. Each label remains adjacent to its value in the DOM, and the mobile layout preserves the same reading order without horizontal scrolling.

</DocSection>

<DocSection id="performance" index="06" title="Performance">

Static Astro markup and CSS Grid only. No hydration, observers, measurement, or duplicated state.

</DocSection>
