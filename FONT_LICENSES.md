# Font licenses

The portfolio bundles webfont files through Fontsource packages. Installed package versions and full license texts remain available in each package directory and are preserved by pnpm-lock.yaml.

| Typeface | Package | License |
| --- | --- | --- |
| Geist Sans | @fontsource-variable/geist | SIL Open Font License 1.1 |
| Geist Mono | @fontsource-variable/geist-mono | SIL Open Font License 1.1 |
| IBM Plex Serif | @fontsource/ibm-plex-serif | SIL Open Font License 1.1 |

Upstream sources:

- Geist: https://github.com/vercel/geist-font
- IBM Plex: https://github.com/IBM/plex
- Fontsource packaging: https://fontsource.org/

The portfolio does not currently ship Caveat because the optional handwritten accent has not passed visual and Vietnamese-language review.
